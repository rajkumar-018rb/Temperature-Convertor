# 🌡️ Temperature Converter

A simple and responsive **Temperature Converter Web Application** built using **HTML, CSS, and JavaScript**. The application allows users to convert temperatures between **Celsius, Fahrenheit, and Kelvin** with input validation and proper handling of invalid temperature values.

## 🚀 Features

* 🌡️ Convert between:

  * Celsius (°C)
  * Fahrenheit (°F)
  * Kelvin (K)
* 🔄 Real-time temperature conversion
* ✅ Numeric input validation
* ⚠️ Handles invalid temperature values
* ❄️ Prevents temperatures below absolute zero
* 📱 Responsive design for different screen sizes
* 🎨 Clean and simple user interface
* ⚡ Built with vanilla JavaScript — no external frameworks required

## 🛠️ Technologies Used

* **HTML5** – Structure of the application
* **CSS3** – Styling and responsive design
* **JavaScript** – Temperature conversion logic and validation

## 🔢 Conversion Formulas

### Celsius to Fahrenheit

```text
°F = (°C × 9/5) + 32
```

### Fahrenheit to Celsius

```text
°C = (°F − 32) × 5/9
```

### Celsius to Kelvin

```text
K = °C + 273.15
```

### Kelvin to Celsius

```text
°C = K − 273.15
```

### Fahrenheit to Kelvin

```text
K = (°F − 32) × 5/9 + 273.15
```

### Kelvin to Fahrenheit

```text
°F = (K − 273.15) × 9/5 + 32
```

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/your-username/temperature-converter.git
```

2. Open the project folder:

```bash
cd temperature-converter
```

3. Open `index.html` in your web browser.

You can also use **VS Code Live Server** to run the project locally.

## 💻 Usage

1. Enter a temperature value.
2. Select the input temperature unit.
3. Select the unit you want to convert to.
4. Click the **Convert** button.
5. The converted temperature will be displayed.

## 🧪 Example

If the input temperature is:

```text
25 °C
```

The converter gives approximately:

```text
77 °F
298.15 K
```
